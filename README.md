# Asistente IA para Licitaciones

Este proyecto permite hacer preguntas en lenguaje natural sobre tu base de datos MySQL de licitaciones.

## Cómo usar

1. Copia `.env.example` a `.env` y completa tus credenciales.
2. Instala dependencias:
   ```bash
   pip install -r requirements.txt

3. Ejecuta la aplicación:
    streamlit run app.py

4. Abre http://localhost:8501 en tu navegador.
